# 泛亚五个工作台源码

每个工作台都提供新版 Demo 与历史源码。进入新版 Demo 目录后，按里面的 README 启动。历史代码目录用于查看此前实现，完整保留的提交序列和分支可以从 GitHub 分支列表打开。

| 老板台账 | [台账 Demo](demo/老板台账) | [台账历史](history/老板台账) |

采购、仓管、销售、客服和台账的历史分支分别以 history/purchase、history/warehouse、history/sales、history/support 和 history/ledger 开头。公开历史副本保留原提交顺序，数据样本使用演示值，私密连接配置和内部业务附件已移出。新版 Demo 使用本地演示数据。
