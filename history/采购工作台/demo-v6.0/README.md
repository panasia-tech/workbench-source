# 泛亚采购工作台 × 闲鱼监控助手 v6.0（全栈融合正式版）

本系统将闲鱼多维商品监控引擎（`shared/sxjk-item-filter.js`、`areas.json`、全域/店铺双轮询、钉钉加签通知、黑名单过滤、Electron `xy-sxjk` 兼容接口）与泛亚数码采购全生命周期工作台深度融合为同一套真实前后端架构系统。

## 快速启动

```bash
export PATH="$HOME/.local/bin:$PATH"
# 1. 构建 Vue 3 前端静态资源至 dist/
cd web && node ./node_modules/vite/bin/vite.js build --outDir ../dist --emptyOutDir && cd ..

# 2. 启动全栈服务（默认监听 http://127.0.0.1:5860）
PORT=5860 node server/index.js

# 3. 运行全栈端到端自动化验证测试（50+ 业务防呆与数据闭环断言）
node tests/fullstack_e2e_verify.mjs
```

## 核心架构与融合防呆体系

- **数据库**：Node 24 原生 `node:sqlite` (`WAL` 模式 + 外键 + 顺序 Schema 迁移 `v1`→`v2`)，28 张核心表承载采购单、快照、监控任务、店铺监听、命中池、二次议价与对账台账。
- **鉴权体系**：`scrypt` 随机盐值哈希 + HMAC-SHA256 签名 Bearer/X-Erp-Token + 5 分钟 5 次失败自动 `429` 防爆破锁定。
- **监控防呆联动**：
  - `403` 行情参考上限锁：全域/店铺监听价格或自动秒拍价格严禁超过《行情参考表》上限；
  - `409` 5% 防红标号池拦截：`闲鱼副号2` (4.71% 退款率，再退 1 单破 5.88%) 禁止绑定高风险自动秒拍或疑似「几乎全新」单，自动推荐绿灯 `闲鱼3号` (1.67%)；
  - `409` 钉钉加签测试前置锁：未通过测试发送的机器人禁止绑定监控任务；
  - `409` 商家黑名单互斥：黑名单卖家自动剔除出轮询且禁止建店铺监听；
  - `400` 防风控轮询校验：单账号间隔 `< 3s` 自动拒绝防风控；
  - `422` 话术三合一防泄漏/防封号/反扯皮扫描：拦内部保密词、站外引流微信词与「小二介入/法庭」等拉高纠纷词。
- **内置原声手绘+实界面教学视频**：`/media/tutorial-v6.mp4` 通过 HTTP `206 Partial Content` 分片流式点播，支持 7 章节精准跳转与交互式聚光灯引导（Spotlight Tour）。
- **Electron 桌面执行桥**：`/electron/` 目录保留了来自 `xianyu-waimai-4.1.11` 的 Playwright/MTOP 桌面端 IPC 适配骨架，并与服务端 `/app/xy-sxjk/*` 及 `/api/auth/me` (`X-Erp-Token`) 无缝兼容。
