# 仓管工作台

本仓库用于独立开发仓管工作台的功能。当前范围包括库存、入库、出库、盘点、验货及SPU匹配。

ERP 共用底座负责登录、共用组件、数据库和跨模块集成。本仓库按原路径保留模块源码，方便提出模块 PR 并集成回 ERP。独立的生产部署需要另行拆分运行依赖。

- 需求单及验收走钉钉和禅道。提交 PR 时附对应任务及验收材料。
- 共用业务流程、H5 说明与讲解视频在[程序员知识库](https://alidocs.dingtalk.com/i/spaces/gBVzxO9dJ5Qa4GOa/overview)。
- 跨模块联调用约定的接口、脱敏样例和必要的联调资料。生产账号、密钥和真实业务数据留在受管系统。

初始模块源码来自 ERP 集成基线 `9b890c7ec9234a4184c5087ea689bf933c2c7ac7`，共 178 个文件。
