# 外部客服工作台 Demo 源码

本目录对应 2026-11-16 桌面版接待台及 2026-11-20 双视角 H5 的工作台演示。Vue 页面、SQLite 演示服务、单文件打包脚本和原有闭环验收脚本均可独立运行。商品、对话、订单、供货方和图片均为示例，场景图和商品示意图由源码生成。

## 本地启动

准备 Node.js 20 或更新版本、npm 和 Python 3.12 或更新版本。在本目录执行。

```sh
cd 前端
npm ci
npm run build
cd ..
python3 cs_server.py
```

浏览器打开 `http://127.0.0.1:5380/`。右上角「视角与更多」可切换外包客服、新人、内部销售和主管，也可进入新人训练。用顶栏「自动发货池」和「全维考核」打开相应抽屉。端口可用 `H5_PORT` 修改，运行数据默认生成在 `.demo-runtime/`，可用 `CS_RUNTIME_DIR` 指向另一本地目录。

## 免起服文件与验收

```sh
python3 pack_single_html.py
python3 tests/verify_cs_closed_loop.py
```

双击生成的 `客服工作台-桌面版H5-单文件直开版.html` 可离线演练。单文件使用浏览器存储，服务版支持本地 SQLite 同步和审计展示。在浏览器分别进入外包、新人、内部销售和主管视角，可观察选货、发保修卡、买家发问后暂停、转内部接管和状态差异。

角色来自演示请求头，交付用于模拟角色切换和成本字段脱敏。外发守卫可以本地验证；聊天、退款、推仓、急停、物流、视频和店铺 KPI 使用本地模拟交互，不向平台或仓管发出真实请求。源文档链接在演示包中留空。
